# @alfanjauhari/config

Shared configuration presets for Oxc, Oxfmt, TypeScript, and Tailwind typography.

The presets intentionally avoid application-specific paths, deployment settings, secrets, and brand tokens. Consumers should keep aliases, generated files, Astro integrations, Cloudflare bindings, and design tokens in their application configuration.

Available entry points:

- `@alfanjauhari/config/oxlint`
- `@alfanjauhari/config/oxlint/base`
- `@alfanjauhari/config/oxlint/solid`
- `@alfanjauhari/config/oxfmt`
- `@alfanjauhari/config/tsconfig/astro-solid`
- `@alfanjauhari/config/tailwind-typography`
